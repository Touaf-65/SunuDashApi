# 📁 ASSETS EMAIL - SUNU DASH

## 🖼️ **Où placer votre logo :**

### **Logo principal :**
- **Fichier** : `logo.jpg`
- **Format** : JPG avec fond transparent ou blanc
- **Taille** : 200px de large minimum
- **Couleurs** : Version couleur principale

### **Logo version blanche (optionnel) :**
- **Fichier** : `logo-white.jpg`
- **Format** : JPG avec fond transparent
- **Taille** : 200px de large minimum
- **Couleurs** : Version blanche pour header sombre

## 📋 **Instructions :**

1. **Copiez votre logo** dans ce dossier
2. **Nommez-le** `logo.png`
3. **Vérifiez** qu'il s'affiche correctement
4. **Testez** les emails avec le nouveau logo

## 🎨 **Spécifications recommandées :**

- **Format** : PNG
- **Résolution** : 200px × 200px minimum
- **Fond** : Transparent
- **Couleurs** : Votre palette de marque
- **Poids** : < 100KB pour un chargement rapide

## 🚀 **Test :**

Après avoir ajouté votre logo, testez avec :
```bash
python test_email_system.py
```
